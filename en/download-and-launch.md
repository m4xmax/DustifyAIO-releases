# Download & launch

## Where to download

Download the bot **only from the official link on Discord** in the relevant DustifyAIO channel.

> Do not download DustifyAIO from random websites, DMs from “support”, or mirrors. That is the most common path to a scam build.

## Installation

1. Open the official download link on Discord
2. Download the latest package
3. **Extract** the archive (if it’s a ZIP)
4. Launch DustifyAIO

## Discord authorization

After launch, authorize with **Discord**.

- You must be a full Dustify member
- You must have the **required role**
- Without the role, the bot **will not let you in**

If access fails, check membership and role. Still stuck? Open a ticket — see [Support](support.md).

## Updates

The bot **updates automatically**.

1. You’ll hear about new versions on Discord
2. The bot will prompt you to restart (or show an update prompt on launch)
3. Just **quit and reopen** the bot

You usually don’t need to re-download the full setup if the update succeeds. After bigger releases, always check the Discord changelog.

## Export / import & backups

**Every section** (Profiles, Proxies, Tasks, …) can be **exported and imported**.

Use this to:

- move data to another PC
- back up before a risky change
- recover after an accidental delete / reset

### Recommended workflow

1. Set up profiles, proxies, tasks, settings
2. **Back up every section** (export)
3. Store exports somewhere safe (not a public Discord channel)

If something errors or you reset by mistake, you won’t have to rebuild everything from scratch.
