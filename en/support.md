# Support

## Where to write

If you have a problem:

1. Open a **ticket**, **or**
2. Write in the **DustifyAIO** chat on Discord

We’ll try to help as well and as fast as we can.

## What to send for an error

So we can actually help, always include:

1. A **screenshot** of the error / UI state
2. A **short description** of what you were doing right before
3. Ideally also: site, guest vs account, proxies yes/no, bot version (if known)

### Example of a good report

> Alza task, account from generator, residential proxy group `CZ-1`. After ATC error “…”. Screenshot below. Bot version from today’s update.

### What to avoid

- only “it doesn’t work” with no screenshot
- a screenshot with no context (which shop / task)
- deleting the task before you save the error text

## Before you write

- Restart the bot (quit / reopen)
- Check Discord role and updates
- Try one clean test task
- Skim this guide (Profiles / Proxies / Settings)

Thanks — better reports mean faster fixes.
