# Generator

The **account generator** creates accounts for supported sites. Only a few shops are supported for now — more will come later.

## How to generate

1. Open **Generator**
2. Select the **site**
3. Enter an email:
   - a specific address, **or**
   - a catchall as `@catchall.com` **or** `catchall.com` — the bot will parse it
4. Choose **how many accounts** to create
5. Password:
   - your own, **or**
   - a strong random password generated by the bot
6. Optionally enable **proxies** (pick a group)
7. Start generation

## Results

- Generated accounts appear in the list beside the form
- Clicking the **password field** **copies the password to your clipboard**
- Accounts can **auto-sync into Profiles** — then finish them into full ready profiles

## Tips

- For Alza, generator → Profiles sync is the fastest path to ready accounts
- Only use catchall if you control the domain
- Generate with proxies if the shop / IP rate-limits signups
- Back up the output (export Profiles); don’t leave passwords only in the clipboard
