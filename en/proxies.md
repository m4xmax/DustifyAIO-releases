# Proxies

DustifyAIO fully supports proxies. Add them, split them into **groups**, then select a group on **Tasks** and in the **Generator**.

## Adding proxies

1. Open **Proxies**
2. Create a group (e.g. `Residential CZ`, `Shopify`, `Generator`)
3. Paste your proxy list
4. Save

Organize groups by use case so you always know what you’re selecting on a task / generator run.

## Testing

In the UI you can:

- **test all proxies** at once
- **test them one by one** to see how each IP performs

Recommendation: test the group before a drop / bigger run. Remove bad proxies so they don’t ruin sessions.
